# 나의 작은 농장 (My Little Farm)

3×3 작은 땅에서 시작해 30×30 대농장으로 키워 가는 **모바일 가로형 픽셀아트 농장 힐링 경영 게임**입니다.
Phaser 3 + TypeScript + Vite 로 만들었고, PWA 로 홈 화면에 설치해 오프라인에서도 플레이할 수 있습니다.

> "처음에는 이것밖에 없었는데 이렇게 커졌다."

## 빠른 시작

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173, --host 로 같은 Wi-Fi 의 휴대폰에서 접속 가능)
npm test           # Vitest — 게임 로직 테스트
npm run typecheck  # TypeScript 검사
npm run build      # 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기
```

휴대폰에서는 가로로 돌려서 플레이하세요. 브라우저 메뉴의 **홈 화면에 추가** 로 앱처럼 설치할 수 있습니다.

## 조작

| 동작 | 모바일 | PC |
| --- | --- | --- |
| 이동 | 왼쪽 가상 조이스틱 (설정에서 Tap To Move 전환) | WASD / 방향키 |

## 주요 기능

- 작물은 하루 끝에 1회 성장(물 준 날만, 비·관개 자동) — 당근 3일 = 오늘 마치기 3번
- 외곽 지역(강가·숲·바위 언덕): 낚시 미니게임·채집·벌목·채광, 생활 숙련도, 도구 업그레이드
- 3×3 시작 → 상하좌우 인접 토지 구매로 최대 30×30(900칸)까지 자유 확장, 집 레벨별 토지 가격 단계
- 첫 튜토리얼 12단계 (집 위치 직접 선택 → 농지 → 당근 → 물 → 보관상자 → 성장 → 수확 → 방문상인 → 판매 → 토지 구매)
- 현실 10분 = 게임 1일, 계절별 낮/밤 길이, 월(10일)/계절(30일)/1년(120일) 달력, 맑음·흐림·비·폭우·눈
- 작물 36종(희귀 3종 포함) 데이터 기반, 제철 판매 +10%, 봄·여름·가을엔 모든 작물 성장, 겨울 밭은 겨울 작물만(나머지는 온실), 죽지 않음
- 농지 내부 업그레이드 (관개/토양/비료/해충/자동 수확) — 다중 선택·드래그 선택 일괄 적용
- 신선도(0~100) 판매가 배율, 부패, 퇴비 재활용, 보관상자/창고/냉장창고(60%)/대형 저온창고(85%)
- 방문상인(2~3일 간격) + 특급상인(약 12% + 비공개 연속 미등장 보정)
- 동물 12종, 개체 ID(예: `COW-000127`), 성별/등급/능력치/특성 20종/혈통 3대, 직접 브리딩만 (자동 번식 없음), 사망 없음
- 축사 내부 자동화(자동 급식/청소/수거/확장), 출하·육가공
- 가공소/주방/방직소/육가공소/퇴비통 — 레시피 50여 종, 요리는 고부가가치
- 농사·목축 이중 레벨 + 스킬트리(44개 기술), 집 Lv.1~6
- 월 운영비(지난달 판매수익의 2~7%), 미납 시 일부 기능만 제한 (게임오버·이자 없음)
- 도감, 농장 전체 관리(탭하면 카메라 이동), 하루/월간 정산, 재정 통계, 설계도 저장/불러오기, 장식
- IndexedDB 3슬롯 저장 + 자동 저장 + 버전/마이그레이션, PWA(오프라인)
- 사운드: BGM 8슬롯(계절×낮밤), 환경음, 효과음, UI — 자산이 없어도 WebAudio 합성음으로 동작

## 그래픽 / 폰트 / 사운드

- 모든 그래픽은 코드로 그린 픽셀아트 플레이스홀더입니다 (`src/assets/art/*`). 이모지를 인게임 그래픽으로 쓰지 않습니다.
  실제 아트로 교체하려면 `BootScene.preload()` 에서 **같은 Asset Key** 로 이미지를 로드하면 됩니다 (예: `player`, `crop_carrot`, `bld_coop`, `it_egg`).
- 폰트: [Galmuri](https://github.com/quiple/galmuri) (SIL Open Font License 1.1) — npm `galmuri` 패키지에서 번들.
- 사운드: 자산이 없으면 WebAudio 합성음. `AudioManager.registerBuffer('bgm_spring_day', buffer)` 로 교체 가능.
