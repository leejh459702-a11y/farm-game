# 나의 작은 농장 · farm-game

Phaser 3, TypeScript, Vite로 구현한 모바일 가로형 농장 경영 게임입니다. 새 게임은 **집이 없는 3×3 토지**에서 시작하며, 집 배치 → 밭 → 당근 → 물주기 → 상자 → 다음 날 → 수확 → 상인 판매 → 첫 500G 토지 확장을 실제로 플레이할 수 있습니다.

## 실행

Node.js 22.12 이상 또는 24 LTS를 권장합니다. 검증 환경은 Node 24입니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 스마트폰에서 같은 Wi-Fi로 시험하려면 `npm run dev -- --host 0.0.0.0`으로 실행하고 PC의 LAN IP와 5173 포트를 사용합니다. 방화벽 접근 권한은 환경에 맞게 설정하세요. LAN HTTP는 게임 실행은 가능하지만 PWA 설치와 서비스 워커는 HTTPS 배포 또는 localhost에서 검증해야 합니다.

```sh
npm test          # TypeScript 확인 + 프로덕션 빌드 + Vitest 55개
npm run build    # dist/ 생성
npm run preview  # http://127.0.0.1:4173
npm run format:check
```

`index.html`을 파일로 직접 열면 ES 모듈과 저장 기능이 정상 실행되지 않습니다. 반드시 개발 서버 또는 정적 웹 서버로 실행하세요.

## 조작

- PC: 방향키 이동, 마우스 타일 선택, 1–5 도구 선택, Space 상황별 행동, Escape 메뉴 닫기.
- 모바일: 왼쪽 조이스틱, 하단 도구, 오른쪽 행동 버튼. 설정에서 Tap To Move를 선택할 수 있습니다.
- 건설: 시설을 고른 후 타일을 눌러 미리보기를 이동하고 **배치 확정**. 녹색은 가능, 빨간색은 불가능한 위치입니다.
- 토지 구매: 건설 → 토지 구매 → 농장에서 구입할 땅 선택. 상하좌우로 붙은 한 칸씩 구매합니다.
- 하루 종료: 집 또는 메뉴의 **오늘 마치기**. 강제 취침과 스태미나는 없습니다.
- 메뉴와 건설 중 시간은 멈춥니다. 건설 완료 버튼으로 일반 플레이에 돌아오세요.
- 건설 모드에서 드래그 이동, 두 손가락 핀치 줌을 지원합니다. PC에서는 휠로 확대할 수 있습니다.

## 구현 범위

32종 계절 작물과 희귀 작물 1종, 12종 동물, 25종 시설, 농사·목축 기술 29종, 집 6단계, 최대 30×30 토지, 계절·날씨·낮밤, 방문상인·특급상인, 신선도·냉장, 수동 브리딩·유전·혈통, 가공·요리·출하, 내부 자동화, 도감·정산·통계·설계도·다중 이동을 구현했습니다. 관련 화면은 탭을 사용해 합쳤으며 [UI_MATRIX.md](docs/UI_MATRIX.md)에 요청한 48개 화면의 진입 경로를 기록했습니다.

게임 로직은 DOM이나 Phaser 렌더링에서 분리했습니다. 작물·동물·시설·레시피·기술 데이터는 `src/data/`, 경제 계산은 `EconomyService`, 저장은 `SaveSystem`에 있습니다. 대부분의 공통 수치는 `BalanceConfig`에서 수정할 수 있습니다.

## 세이브와 PWA

IndexedDB의 `my-little-farm` 데이터베이스에 슬롯 3개를 저장합니다. 하루 시작/종료, 시설 변경, 주요 거래, 30초 주기와 화면 숨김 시 자동 저장하고 수동 저장도 제공합니다. 세이브는 요청 시점의 스냅샷을 순서대로 기록합니다. 미래 버전과 기본 형식이 손상된 세이브는 거절합니다. 브라우저 사이트 데이터를 지우면 로컬 저장도 사라지므로 세이브 화면에서 JSON 백업을 내보낼 수 있습니다.

프로덕션 빌드는 서비스 워커와 가로 방향 manifest를 생성합니다. 첫 온라인 로딩과 캐시 설치를 마친 후 동일 주소를 오프라인으로 열 수 있습니다. 개발 서버에는 서비스 워커를 등록하지 않습니다. 개발/미리보기/배포 주소는 서로 다른 저장 공간을 사용합니다.

## 그래픽과 소리

첨부 UI 이미지는 색감과 정보 배치의 참고 자료로 사용했습니다. 실제 게임은 32px 캔버스에서 생성한 교체 가능한 임시 픽셀 자산을 사용하며 이모지를 게임 그래픽으로 사용하지 않습니다. 사운드는 Web Audio 임시 멜로디와 효과음이며, 계절별 낮/밤 BGM 슬롯을 제공합니다. 브라우저 정책 때문에 소리는 첫 버튼 조작 후 재생됩니다.

현재 버전은 **로컬 플레이와 기능 검증이 가능한 0.1 버전**입니다. 출시에 앞서 정식 아트·음원 교체, 장기 경제 밸런스 조정, 실제 Android/iOS 기기의 멀티터치·PWA 설치·성능 검증이 필요합니다. 테스트 결과와 검증하지 않은 범위는 [QA.md](docs/QA.md)를 참고하세요.

## 후반 화면 검증용 개발 시나리오

개발 서버에서 `http://127.0.0.1:5173/?qa=late`를 열면 확장 농장, 축사, 임신 동물, 냉장 창고, 가공 작업을 가진 QA 시나리오가 열립니다. 일반 세이브와 다른 DB를 사용하며 자동 저장을 끕니다. 이 시나리오는 프로덕션 빌드에 포함되지 않습니다. 일반 새 게임의 시작 조건을 변경하지 않습니다.
