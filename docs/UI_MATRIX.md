# 요청한 48개 화면의 진입 경로

동일한 기능은 독립 패널의 탭으로 합쳤습니다. 시설은 농장에서 선택한 후 오른쪽 행동 버튼으로 관리 화면을 엽니다.

| 번호 | 요청 화면 | 구현 경로 |
| --- | --- | --- |
| 1 | 게임 시작 | 최초 메뉴 |
| 2 | 새 게임 | 메뉴 → 새 농장 시작하기 |
| 3 | 이어하기 | 메뉴 → 이어하기 → 슬롯 |
| 4 | 설정 | 메뉴 또는 일시정지 → 설정 |
| 5 | 집 위치 선택 | 새 게임 첫 튜토리얼, 녹색/적색 미리보기 |
| 6 | 일반 튜토리얼 | 첫 농장 이야기 안내 카드 |
| 7 | HUD | 일반 플레이 |
| 8 | 시간/날씨/계절 | 상단 날짜 버튼 |
| 9 | 인벤토리 | 오른쪽 가방 |
| 10 | 건설 | 오른쪽 건설 |
| 11 | 토지 구매 | 건설 → 토지 구매 |
| 12 | 농지 관리 | 밭 선택 → 살펴보기 |
| 13 | 씨앗 선택 | 씨앗 도구 → 밭, 또는 밭 관리 |
| 14 | 작물 심기 | 씨앗 선택 → 여기에 심기 |
| 15 | 작물 정보 | 밭 관리 → 밭 정보 |
| 16 | 관개 | 밭 관리 → 내부 업그레이드 |
| 17 | 토양 | 밭 관리 → 내부 업그레이드 |
| 18 | 비료 | 밭 관리 → 내부 업그레이드 |
| 19 | 작물 도감 | 도감 → 작물 |
| 20 | 동물 목록 | 오른쪽 동물 |
| 21 | 동물 상세 | 동물 목록 → 자세히 보기 |
| 22 | 축사 관리 | 농장에서 축사 선택 → 시설 관리 |
| 23 | 축사 자동화 | 축사 관리 → 자동화 |
| 24 | 브리딩 | 동물 목록 → 브리딩 |
| 25 | 브리딩 결과 | 출산일 결과 패널, 정산의 출산 결과 |
| 26 | 혈통도 | 동물 상세 → 혈통도, 기술 필요 |
| 27 | 동물 도감 | 도감 → 동물 |
| 28 | 방문상인 | 오른쪽 상인 |
| 29 | 특급상인 | 특급 방문일 동일 패널, 보너스 표시 |
| 30 | 판매 | 상인 → 판매 |
| 31 | 구매 | 상인 → 씨앗/동물/상품 |
| 32 | 창고 | 상자/창고 선택, 보관함 선택 메뉴 |
| 33 | 냉장창고 | 냉장창고 선택, 신선도 보호 표시 |
| 34 | 가공소 | 시설 또는 농장 관리 → 가공/요리 |
| 35 | 레시피 | 가공 → 레시피 |
| 36 | 요리 | 가공 → 요리 |
| 37 | 농사 스킬트리 | 연구 → 농사 |
| 38 | 목축 스킬트리 | 연구 → 목축 |
| 39 | 집 업그레이드 | 집 선택 또는 관리 → 집 업그레이드 |
| 40 | 전체 관리 | 오른쪽 농장 관리 |
| 41 | 하루 정산 | 하루 종료 후 |
| 42 | 월간 정산 | 월말 종료 후 |
| 43 | 재정 통계 | 전체 관리 또는 메뉴 → 재정 통계 |
| 44 | 농장 꾸미기 | 건설 → 꾸미기 |
| 45 | 설계도 | 건설 → 배치 또는 메뉴 → 설계도 |
| 46 | 일시정지 | 오른쪽 메뉴 |
| 47 | 세이브 | 메뉴 → 저장/불러오기 |
| 48 | 모바일 설정 | 설정의 조작/진동/UI/카메라/FPS 항목 |

일부 개체 특성은 외형·애착을 위한 정보형 특성입니다. 생산형 특성과 빠른 성장에는 실제 효과가 적용됩니다. 해충 방지는 발생률 감소와 제거를 수행합니다. 주요 진입 경로는 관련 게임 명령을 호출합니다.
